머신러닝을 위한 미분 기초#

근거 자료: 박성호, 「머신러닝/딥러닝을 위한 수치미분 (I) - 미분 • 편미분 • 체인룰」 (ML_LEC_09)

학습 목표#

  1. 미분의 의미를 “입력에 대한 출력의 민감도” 관점에서 설명할 수 있다.

  2. 다항함수, 지수함수, 로그함수의 미분 공식을 알고 계산할 수 있다.

  3. 편미분과 연쇄법칙(chain rule)의 뜻을 이해하고 계산할 수 있다.

지난 시간 복습#

오늘의 질문 🤔 인공지능은 어떻게 “똑똑해질까”?
→ 틀린 정도(오차)를 줄이는 방향으로 자기 안의 숫자(가중치)를 조금씩 고칩니다.
　 그런데 어느 방향으로, 얼마나 고쳐야 할까? 그것을 알려 주는 도구가 바로 미분 입니다.

핵심 정리#

① 평균변화율에서 미분계수로

\(x\) 가 \(a\) 에서 \(a + h\) 로 변할 때 \(f(x)\) 의 평균변화율은 \(\displaystyle \frac{f(a + h) - f(a)}{h}\) 이고, 이는 두 점을 잇는 할선의 기울기이다.
\(h\) 를 0 에 한없이 가깝게 하면

\(\displaystyle f'(a) = \lim_{h\to 0} \frac{f(a + h) - f(a)}{h}\)

이 값은 \(x = a\) 에서의 접선의 기울기이다.

② 미분계수 = 민감도

\(h\) 가 충분히 작으면 \(f(a + h) \fallingdotseq f(a) + f'(a) \times h\) 이다. 즉 입력을 \(h\) 만큼 바꾸면 출력은 약 \(f'(a)\) 배인 \(f'(a)h\) 만큼 변한다.
예) \(f(x) = x^{2}\) 에서 \(f'(3) = 6\) 이므로 \(f(3.01) \fallingdotseq 9 + 6 \times 0.01 = 9.06\) (실제 값 9.0601)

③ 자주 쓰는 도함수

\((c)' = 0\),　\((ax^{n})' = nax^{n-1}\),　\((e^{x})' = e^{x}\),　\((e^{-x})' = -e^{-x}\),　\(\displaystyle (\ln x)' = \frac{1}{x}\)

④ 편미분

변수가 여러 개인 함수에서 한 변수만 움직이고 나머지는 상수로 본다.
\(f(x, y) = 2x + 3xy + y^{3}\) 이면 \(\displaystyle \frac{\partial f}{\partial x} = 2 + 3y\),　\(\displaystyle \frac{\partial f}{\partial y} = 3x + 3y^{2}\)
기하학적으로 \(\displaystyle \frac{\partial f}{\partial x}\) 는 곡면을 \(y =\) (상수) 인 평면으로 자른 단면 곡선의 접선의 기울기이다.

⑤ 연쇄법칙

\(y = f(t), t = g(x)\) 이면　\(\displaystyle \frac{dy}{dx} = \frac{dy}{dt} \times \frac{dt}{dx} = f'(g(x)) \times g'(x)\)
예) \(y = e^{3x^{2}}\) : \(t = 3x^{2}\) 로 놓으면 \(\displaystyle \frac{dy}{dx} = e^{t} \times 6x = 6x e^{3x^{2}}\)
변화가 단계마다 ‘몇 배’ 로 커지는지 곱해 가는 것이 연쇄법칙의 뜻이다. (아래 애니메이션 3)

개념 다지기 1. 미분이란? - 입력에 대한 민감도#

\(\displaystyle f'(x) = \lim_{\Delta x\to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}\)

미분은 한마디로

“입력 \(x\) 를 지금 값에서 아주 조금 바꾸면, 출력 \(f(x)\) 는 얼마나 변하는가?” = 함수 \(f(x)\) 가 입력의 미세한 변화에 얼마나 민감하게 반응하는가?

[이해해 보기] \(f(x) = x^{2}\) 이면 \(f'(x) = 2x\)#

  • \(f(3) = 9\) → 입력 \(x = 3\) 일 때 출력은 9

  • \(f'(3) = 6\) → \(x = 3\) 에서 \(x\) 를 아주 조금 변화시키면, \(f(x)\) 는 그 변화량의 ( 　 ) 배만큼 변한다.

[확인 1] \(x\) 를 3 에서 3.01 로 0.01 만큼 늘리면 \(f(x)\) 는 약 \(6 \times 0.01 =\) ( 　　 ) 만큼 늘어난다. 실제로 계산하면 \(f(3.01) - f(3) = 9.0601 - 9 =\) ( 　　　 ) 으로 거의 같다!

\(\Delta x\) 가 작아질수록 (변화량 \(\div \Delta x\)) 가 6 에 가까워집니다. 이 값이 바로 미분계수 \(f'(3) = 6\) 입니다.

애니메이션 1. 곳곳의 민감도 = 도함수#

점이 \(f(x) = x^{2}\) 위를 움직이면서 그 점의 접선의 기울기 (민감도) 를 오른쪽 그래프에 찍습니다. 찍힌 점들을 이으면 도함수 \(f'(x) = 2x\) 가 됩니다.

[관찰 1] 기울기가 음수인 곳에서 \(x\) 를 늘리면 \(f(x)\) 는 ( 늘어난다 / 줄어든다 ). 기울기가 0 인 곳 \(x =\) ( 　 ) 에서 \(f(x)\) 는 가장 ( 크다 / 작다 ).

  • 머신러닝에서 미분을 왜 할까? 인공지능은 오차를 줄여야 합니다. 오차를 나타내는 함수의 기울기(미분값) 를 알면 “가중치를 늘려야 오차가 줄어드는지, 줄여야 하는지” 를 알 수 있습니다. (→ 제 6편 경사하강법)

애니메이션 3. 변화가 전달되는 연쇄법칙#
