제 9 편

XOR 문제 - 직선 하나로는 나눌 수 없다#

근거 자료: 박성호, 「머신러닝 XOR 문제 - AND • OR • NAND • XOR」 (ML_LEC_18), 「Python class」 (ML_LEC_05)

학습 목표#

  1. 논리게이트 AND, OR, NAND, XOR 의 진리표를 머신러닝 학습 데이터로 볼 수 있다.

  2. 로지스틱 회귀 하나로 AND, OR, NAND 는 학습되지만 XOR 은 학습되지 않는 이유를 설명할 수 있다.

  3. NAND, OR, AND 를 층으로 쌓아 XOR 을 해결하고, 이것이 신경망(딥러닝)의 핵심 아이디어임을 이해한다.

지난 시간 복습#

  • 제 8편: 로지스틱 회귀의 결정 경계는 직선 \((W_{1}x_{1} + W_{2}x_{2} + b = 0)\) 입니다.

  • 도전 과제: (0,0)·(1,1) 은 0, (0,1)·(1,0) 은 1 인 점들을 직선 하나로 나눌 수 있을까?

AND 는 직선 \(x_{1} + x_{2} = 1.5\), OR 는 직선 \(x_{1} + x_{2} = 0.5\) 로 0 과 1 을 나눌 수 있다. (아래 애니메이션 1)

② XOR 은 직선 하나로 나눌 수 없다 (증명)

어떤 직선 \(w_{1}x_{1} + w_{2}x_{2} + b = 0\) 이 XOR 을 나눈다고 하자. 1 인 점에서는 양수, 0 인 점에서는 음수라 하면

  • (0, 0) : \(b < 0\)

  • (1, 1) : \(w_{1} + w_{2} + b < 0\)

  • (0, 1) : \(w_{2} + b > 0\)

  • (1, 0) : \(w_{1} + b > 0\)

위의 두 식을 더하면 \(w_{1} + w_{2} + 2b < 0\), 아래 두 식을 더하면 \(w_{1} + w_{2} + 2b > 0\) → 모순.
따라서 로지스틱 회귀 하나(직선 하나)로는 XOR 을 학습할 수 없다. (아래 애니메이션 2)

③ 층을 쌓으면 풀린다

\(\mathrm{XOR}(x_{1}, x_{2}) = \mathrm{AND}( \mathrm{NAND}(x_{1}, x_{2}), \mathrm{OR}(x_{1}, x_{2}) )\)

1층의 출력 \((s_{1}, s_{2}) = (\mathrm{NAND}, \mathrm{OR})\) 로 점을 옮기면 (0, 0) → (1, 0), (0, 1) 과 (1, 0) → (1, 1), (1, 1) → (0, 1) 이 되어, 새 평면에서는 직선 \(s_{1} + s_{2} = 1.5\) 로 나눌 수 있다. (아래 애니메이션 3)
층이 데이터를 ‘나누기 쉬운 공간으로 옮기는 것’ 이 신경망의 핵심 아이디어이다.

애니메이션 1. 네 게이트의 결정 경계가 학습되는 모습#

배경색은 출력이 1 일 확률(빨강 1, 파랑 0), 검은 선은 결정 경계(sigmoid = 0.5) 입니다. ● 정답 1, ✕ 정답 0

[관찰 1] AND, OR, NAND 는 직선 하나로 ● 와 ✕ 가 깔끔하게 나뉜다. XOR 은 배경이 거의 ( 한 가지 색 / 두 가지 색 ) 이고, ● 와 ✕ 를 나누지 못한다.

애니메이션 2. 정말로 직선 하나로는 안 될까?#

직선을 여러 방향, 여러 위치로 움직여 보며 XOR 의 네 점 중 몇 개를 맞히는지 세어 봅시다.

[관찰 2] 어떤 직선을 그어도 최대 ( 　 ) / 4 개밖에 맞히지 못한다. 💡 이처럼 직선 하나로 나눌 수 없는 데이터를 선형 분리 불가능 하다고 합니다. 1969년 이 사실이 알려지면서 인공지능 연구가 한동안 침체되기도 했습니다.

애니메이션 3. 1층이 ‘공간을 바꿔’ 준다#

1층(NAND, OR)을 지나면 점 \((x_{1}, x_{2})\) 가 새로운 점 \((s_{1}, s_{2})\) 로 옮겨집니다. 옮겨진 공간에서는 직선 하나(AND 의 결정 경계)로 나눌 수 있게 됩니다!

[관찰 3] (0, 1) 과 (1, 0) 은 이동한 뒤 같은 점 ( 　, 　 ) 으로 모인다. (0, 0) 은 ( 　, 　 ), (1, 1) 은 ( 　, 　 ) 으로 옮겨진다.

insight - 신경망(딥러닝)의 핵심 아이디어#

  • 게이트 하나하나는 로지스틱 회귀 (선형 회귀 + sigmoid) 입니다.

  • 앞 층의 출력을 다음 층의 입력으로 넣어 여러 층(multi-layer) 으로 쌓으면, 직선 하나로는 풀 수 없던 문제도 풀 수 있습니다.

  • 각 층은 데이터를 나누기 쉬운 공간으로 옮겨 주는 역할을 합니다.

→ 이것이 바로 신경망(Neural Network) 이고, 층을 깊게(deep) 쌓은 것이 딥러닝(Deep Learning) 입니다!
