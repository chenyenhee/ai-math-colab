CNN - 합성곱으로 사진의 특징 찾기#

근거 자료: 박성호, 「CNN (I) - 컨볼루션 연산 • 풀링 • 패딩」 (ML_LEC_32)

학습 목표#

  1. 합성곱(컨볼루션) 연산을 손으로 계산하고, 필터가 특징을 찾는 원리를 설명할 수 있다.

  2. ReLU 와 풀링(pooling)의 역할을 알고 계산할 수 있다.

  3. 패딩과 스트라이드에 따른 출력 크기를 공식으로 구할 수 있다.

지난 시간 복습#

  • 제 13편 도전 과제: 지금까지의 신경망은 28 × 28 사진을 784 개짜리 한 줄로 펴서 넣었습니다. → 픽셀끼리 위아래·좌우로 이웃 한다는 정보가 사라집니다.

  • CNN (Convolutional Neural Network, 합성곱 신경망) 은 사진을 2차원 그대로 다루며 특징(feature)을 찾습니다.

핵심 정리#

① 합성곱(컨볼루션)

입력 A, 필터 F (FH × FW) 일 때

C(i, j) = Σp Σq A(i + p, j + q) × F(p, q)　(+ 바이어스)

필터가 덮은 부분과 필터의 같은 자리끼리 곱해 모두 더한다. (아래 애니메이션 1)
예) 왼쪽 위 : 1×2 + 2×0 + 3×1 + 0×0 + 1×1 + 2×2 + 3×1 + 0×0 + 1×2 = 15

② 출력 크기

입력 (H, W), 필터 (FH, FW), 패딩 P, 스트라이드 S 이면

OH = (H + 2P − FH) / S + 1,　OW = (W + 2P − FW) / S + 1

예) (28, 31), 필터 (5, 5), P = 2, S = 3 → (10, 11)

③ 필터는 무늬 탐지기

세로선 필터 ( 1 0 −1 / 1 0 −1 / 1 0 −1 ) 은 왼쪽이 밝고 오른쪽이 어두운 곳에서 큰 값을 낸다. 같은 필터를 사진 전체에서 함께 쓰므로, 3 × 3 필터 하나는 가중치 9 개로 사진 어디서나 같은 무늬를 찾는다. (아래 애니메이션 2)

④ ReLU 와 풀링

ReLU(x) = max(0, x),　2 × 2 max pooling 은 구역의 최댓값만 남겨 크기를 절반으로 줄인다.
24 × 24 → (3 × 3 컨볼루션) 22 × 22 → (풀링) 11 × 11 (아래 애니메이션 3)

개념 다지기 1. CNN 의 구조#

 일반 신경망 :  입력 → [완전연결 + sigmoid] → [완전연결 + sigmoid] → 출력
 CNN       :  입력 → [conv → ReLU → pooling] → [conv → ReLU → pooling] → [완전연결] → 출력

층

하는 일

conv (합성곱)

필터(가중치 묶음)를 사진 위로 옮겨 가며 곱해 특징(feature) 을 뽑는다

ReLU

활성화 함수. 음수는 0, 양수는 그대로 → ReLU(x) = max(0, x)

pooling (풀링)

작은 구역을 최댓값(max) 등 하나로 압축 해서 계산량을 줄인다

애니메이션 3. conv → ReLU → max pooling 한 번에 보기#

크기는 24 × 24 → 22 × 22 → 11 × 11 로 줄어들었지만, 세로 획이 있는 곳 이라는 핵심 정보는 남아 있습니다. CNN 은 이런 층을 여러 번 쌓아 점점 복잡한 특징(획 → 곡선 → 숫자 모양)을 찾습니다.
