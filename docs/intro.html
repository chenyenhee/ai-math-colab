인공지능을 위한 수학#

미분에서 출발해 신경망, 오차역전파, CNN 과 RNN 까지. 편마다 핵심 수식을 정리하고, 그 수식이 실제로 어떻게 움직이는지 애니메이션으로 확인합니다.

Ⅰ수학 도구

  1. 1머신러닝을 위한 미분 기초
  2. 2수치미분 - 파이썬으로 미분하기
  3. 3벡터와 행렬 - numpy 로 데이터 다루기

Ⅱ머신러닝 기초

  1. 4머신러닝의 개념과 종류
  2. 5선형 회귀 (1) - 오차와 손실함수
  3. 6선형 회귀 (2) - 경사하강법
  4. 7선형 회귀 (3) - 파이썬으로 직접 학습시키기

Ⅲ분류와 신경망

  2. 9XOR 문제 - 직선 하나로는 나눌 수 없다

  1. 12오차역전파 (1) - 연쇄법칙으로 한꺼번에 미분하기
  2. 13오차역전파 (2) - 은닉층 공식과 MNIST 고속 학습

공부하는 방법#

  1. 왼쪽 차례에서 편을 고릅니다. 페이지 아래의 다음 으로 순서대로 넘어갈 수 있습니다.

  2. 편마다 맨 앞의 핵심 정리 로 수식을 먼저 익히고, 이어지는 설명과 애니메이션 으로 그 수식을 눈으로 확인합니다. 애니메이션은 ▶ 를 누르면 재생됩니다.

  3. 코드로 직접 해 보려면 페이지 위쪽 로켓 버튼 → Colab 을 누릅니다. 코랩이 열리면 파일 → Drive에 사본 저장 부터 하고, 맨 위 준비 셀부터 한 셀씩 실행합니다.

  4. 연습 문제의 정답은 코랩 학습지에서 확인합니다.

박성호(neowizard), 「파이썬으로 구현하는 머신러닝 / 딥러닝」 강의 내용을 바탕으로 수업용으로 새로 쓴 학습지입니다.
